## Summary

Epic 11 delivered per-case authored documentation reachable as a typed property (`case.docs: AttributedString`) across the public mode enums — the `DocumentedCase` protocol + a total `Bundle.module` accessor (Mutex-cached), a **49-file canonical Markdown corpus**, the `DocumentationValidatorTests` + FR-50 drift gate, a parallel DocC catalog with a one-way transclude generator, and the demo "?" popover wired to the real prose. This was the **first library-shipping, `main`-bound epic since Epic 8** — the demo-only byte-identity safety net of Epics 9–10 did not apply, yet the OA300 / GiantSteps accuracy floors held throughout (the corpus is additive/docs-only; no DSP change).

## What went well

1. **The total-accessor design was the right architectural bet.** The accessor is non-optional, non-throwing, owns its own `"Documentation unavailable"` fallback (FR-49). The known consequence — a green build never proves authoring correctness, since a missing `.md` silently returns the fallback — was handled by moving correctness-proof off the compiler onto a **dedicated gate** (11.4's drift validator). Right shape for the problem.
2. **A story-one decision protected story-3b.** 11.1 flipped SPM `.process → .copy` (KDD-E6 amendment), which preserved the `Documentation/<Type>/` subdir structure and pre-empted the same-basename collision between `AbstainReason/sourceSpecific.md` and `DemotionReason/sourceSpecific.md`.
3. **The authoring contract held across all 49 files** — three bold-leads (`What`/`When`/`Tradeoff`), a mandatory concrete failure-mode sentence per Tradeoff, 200–400 words, 10 KB ceiling, inline-only markdown. The block-element bans are the *render-path* constraint (`AttributedString(interpretedSyntax: .inlineOnlyPreservingWhitespace)`), not style preference.
4. **An empirically-disproven rule was retired cleanly.** KDD-E4's premise — that `case .default:` mis-parses under SwiftLint — was tested (11.2 DD-8) and found false (`.default` matches `.level7` via `~=`); the custom rule was dropped and architecture.md/epics.md carry supersession notes. No cargo-culting.
5. **Every Epic-10 process fix followed through** (see below) — the retrospective loop is working.

## What was bumpy (systems, no blame)

1. **FR-50 drift can't be made fully mechanical** (W84/W85). The five non-`CaseIterable` associated-value enums (`EnsemblePolicy`, `MLExecutionPolicy`, `DownbeatResult`, `AbstainReason`, `DemotionReason`) are hand-rostered. The no-`default:` compile tripwire forces a `case` arm on a new case, but Swift can't enumerate a non-`CaseIterable` enum at runtime, so it can't force the developer to also add the case to the representative list. Accepted as an honest limit, documented verbatim in the tripwire. (Nuance vs. Epic-10 AI-4, which predicted "exhaustive `CaseIterable` switch at test time" — half right; exhaustive for the `CaseIterable` enums, tripwire-guarded for the rest.)
2. **Two specs shipped oversized.** 11-5 and 11-6 both carry `warnings: [oversized]`; 11-5 also set `followup_review_recommended: true`. Not a defect, but a growth signal for a docs-heavy epic. (Observed; not promoted to a formal AI.)
3. **Real test debt on the transclude generator** (W87). `scripts/docc-transclude.py` has genuine branching (front-matter strip, atomic temp-build-then-swap with rollback, path-overlap guard, `--check` byte-compare, empty-corpus floor) and **a regression already slipped once** (PR #101 `--check`-vs-clean-checkout P2), yet it has zero unit tests — `scripts/` has no pytest harness and CI runs no uv. Highest latent risk in the epic. → **promoted to an action item.**
4. **An API smell documented but not fixed** (W83). `AnalysisIntensity.progressiveThreshold: Double?` is behaviorally a `Bool` — the sole consumer only checks `== nil`; the `0.40` payload is never compared. 11.3b corrected the docs to say so; the shape still misleads. → **promoted to an action item** for the next breaking-API pass.
5. **The operator-closeout tail recurs across epics** (observation). Epic 9 closed with operator smokes open (AI-5), Epic 10 flipped `done` with the Mac gauntlet as a tracked pre-squash AI (AI-2), and Epic 11 now has 11-1/11-6 at `review` on the same operator-owned closeout. The GUI-smoke/separate-LLM gate is *correct* discipline — the pattern is that the board keeps carrying an open operator tail per epic. (Named here; not promoted to a formal AI — the gate is working as intended.)
