## What went well

1. **The Epic 8 factual-claims-grep action item paid off directly.** Epic 8 found
   citation drift in 6 of 8 stories; every Epic 9 story re-verified every cited
   path/line against the current tree before dev. Result: **zero drift-caused rework.**
   Clean follow-through on the prior retro's headline action item.
2. **Adversarial review caught genuine load-bearing bugs pre-merge**, not nitpicks:
   - 9-2: all three review layers *independently* converged on the winner-badge bug —
     the pre-ML trace's `.ml` row is always abstained, so an `.ml` winner mis-badged a
     DSP row, and a confidence-1.0 file tag could steal the badge under `.dspOnly`.
   - 9-3: Codex caught a **self-disabling CI gate** — the `if grep; then exit 1` shape
     printed `PASS` when it could not see the files at all (grep error ≥2 treated as
     no-match). A gate that silently stops gating is worse than no gate. HIGH×2.
3. **Reuse-first held.** 9-1 mirrored the merge-strategy persistence mechanism exactly
   rather than inventing parallel plumbing; 9-2 reused `monoFloat` + the existing trace
   snapshot. The demo stayed coherent.
4. **Recorded-decision discipline was consistent.** Three D1s (subtitle-fragment render,
   `Table(sortedRows,…)` vs literal `Table(of:…)`, BYOW grandfather) documented
   interpretations of over-reaching ACs rather than deviating silently.

## What was bumpy (systems, no blame)

1. **MainActor-default-isolation friction recurred and is structural.** Learned in 9-1
   (implicit `@MainActor` on demo types → pure-value tests need annotation), carried
   forward as PSI — and still cost 9-2 three compile reds: a non-`Sendable`
   `KeyPathComparator` in a `@State` default, `static` test helpers called from instance
   `@Test`s, and a MainActor-isolated row model blocking off-actor tests + `TableColumn`
   keypaths (fixed with `nonisolated struct`). The lesson was captured; the friction
   will recur for Epic 10's new Canvas/readout/picker views unless pre-empted.
2. **Epic ACs are written slightly too literally about implementation spelling.** All
   three recorded decisions are the same shape, and 9-2's AC5 literal whole-tree
   `grep ensembleDecision` would have *deleted the golden-locked JSON export* had it been
   taken literally. Each was caught by Codex spec-review + a recorded decision.
3. **Completion notes mildly over-claim coverage.** 9-1 test count was off by one; 9-2
   listed empty-state-view + a11y "tests" that were actually operator GUI-smoke. Review
   corrected each — a repeating, low-severity pattern.
4. **Branch topology got messy (process, not code).** 9-1 was accidentally squash-landed
   to develop (mistaken for epic-8), forcing a fresh `rterhaar/epic-9` and a *second*
   squash, plus the ensemble relayout as stacked PR #90 (merged as `0b2dc8e`).

## Fixes made during this retro (commit `d0fc69b`, on `rterhaar/epic-9`)

Two 9-1 deferred-work items resolved before closing the retro (demo-only; `Sources/`
and `Tests/` byte-identical; full demo gauntlet green — build/test/lint):

- **Non-`String` preference self-heal (both keys).** Hydrate now detects presence via
  `object(forKey:)` instead of `string(forKey:)`. A non-`String`, non-coercible value
  (e.g. an array) under `preferredMergeStrategy` or `preferredEnsemblePreset` previously
  took the absent branch and was left on disk to be silently ignored every launch; it is
  now removed and healed, matching the unrecognized-string path. Fixed for both keys
  together (edge #1). New tests assert via `object(forKey:)` on both keys.
- **Copy Config ML attach hint (edge #4).** `generateConfigSnippet` now emits an
  `opts.mlTechnique = try BNNSTechnique(modelURL:)` hint for the three ML-invoking
  presets, so the copied config reproduces the picker's run instead of abstaining ML.
  DSP-only stays a 5-line snippet. Shape test split into DSP-only (5 lines) / ML-invoking
  (7 lines).
