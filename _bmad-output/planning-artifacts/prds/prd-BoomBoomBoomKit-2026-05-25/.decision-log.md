## 2026-05-25 — Operator additions: Tony half-tempo handling + aubio reference files

**Tony half-tempo concern (Epic B):** operator flagged that Tony manually labeled some songs as half-tempo for a period. The labeler must handle this. **Verified existing tooling already does:**

- `scripts/tony-tunes-labels.py:71` defines `HALF_TIME_BOOST = 1.35`
- Lines 213-214 apply the boost when `raw_bpm < 100.0 AND factor == 2.0`
- Octave expansion at line 188 (`if bpm < 100.0`) generates the doubled variant

Mechanics: when Tony labeled a DnB track at 87 BPM (half-tempo), the labeler expands variants `[87, 174]`, boosts the 174 variant by 1.35×, then clusters with other signals (DSP, grid, playlist). If DSP and grid both land near 174, the 174 cluster wins despite Tony's 87. **Epic B FR-12 strengthened** to explicitly require diagnostics validate this handling on representative half-tempo tracks.

**Aubio reference files (Epic C):** operator pointed to specific files at `github.com/aubio/aubio/blob/master/`:
